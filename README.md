# GridMind Agent Infra

面向园区微电网的多 Agent 策略生成、调度验证与安全执行基础设施。

本项目用于 GOAI Agent Infra「新智基座」赛道的初赛方案沉淀。核心想法不是做普通能源看板，也不是让大模型直接给储能下控制指令，而是把微电网场景里原本需要为每个客户单独编写的策略代码，升级为一套可生成、可验证、可审批、可回滚、可审计的多 Agent 策略运行系统。
