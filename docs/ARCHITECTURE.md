# Architecture Reference

完整且持续维护的架构文档位于项目根目录 [ARCHITECTURE.md](../ARCHITECTURE.md)。

早期提案采用“数据、调度、审核”三个 Agent，并把执行视为调度 Agent 的内部步骤。当前可运行
版本已根据产品核心重新划分为四个独立职责：

1. 感知 Agent：核验负荷、光伏、SOC、电价、设备状态和生产计划。
2. 调度 Agent：先回放原 EMS 固定策略，再通过确定性优化器生成新策略。
3. 审核 Agent：独立复算全部硬约束，并证明新策略优于原策略。
4. 执行 Agent：将获批计划映射为结构化命令，模拟下发并持续确认结果。

负荷、天气、设备、SOC 或生产计划变化会创建新的子任务，重新经过四个 Agent 的完整闭环，
且不得复用旧审批。当前版本没有接入 AgentTeams、MCP 或真实设备。
