# 初赛作品简介草案

项目名称：GridMind：园区微电网多 Agent 策略运行基础设施

GridMind 面向工业园区微电网和储能运营场景，解决传统储能调度策略高度依赖客户定制代码、交付慢、复用差、缺少验证与审计的问题。系统基于 AgentTeams 设计数据感知 Agent、调度行动 Agent、安全审核 Agent 三类核心角色，完成从多源运行数据接入、异常识别、客户目标理解、调度策略生成、仿真验证、安全审批、模拟执行到复盘沉淀的端到端闭环。

项目创新点在于不让大模型直接控制电力设备，而是采用「LLM 编排 + 优化求解 + 仿真验证 + 规则审核」的混合架构，把客户策略需求转化为可解释、可验证、可回滚的调度方案。核心 Skill 包括微电网事件接入、调度策略生成、仿真校验、审批回滚和复盘沉淀，可复用于不同园区、不同储能配置和不同业务目标。

Demo 将聚焦「光伏出力骤降、储能温度告警、峰值电价临近」场景，展示系统如何生成多套策略、拦截不安全方案、请求人工审批、执行保守调度并输出审计证据包。项目具备清晰行业价值和开源复用潜力，可作为能源调度 Agent 从 Demo 走向 Production 的基础设施样例。
